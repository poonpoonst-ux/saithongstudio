SAITHONG STUDIO

A studio for visual storytelling.

SAITHONG STUDIO brings illustration, moving image, digital worlds and spatial design into one creative practice. We work with Thai and international briefs across screen, print and physical environments.

A project can start with a single character, a product sketch or an idea for a scene. We help translate that starting point into a visual direction and a practical production plan.
